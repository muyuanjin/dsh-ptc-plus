<h3 id="cn-v055">宿主适配</h3>

* 适配 DSH `0.2.2-alpha.3` 的公共工具执行接口，保留上一代宿主的调用方式；兼容性按宿主提供的公共能力判定

<h3>修复</h3>

* 新版 DSH 中，`edit_run_code` 接受的修订保留原调用关系和本次运行可用的工具范围，继续遵循宿主策略与取消决定；后续单元格能继续使用修订后的状态

<h3>升级</h3>

* Node.js 需同时满足插件的 `^22.19.0 || >=24.0.0` 与所选 DSH 的要求；DSH `0.2.2-alpha.3` 要求 Node.js `>=24.9.0`
* 无需迁移插件配置；升级后重启 DSH。插件升级不会自动改写历史会话日志

```sh
dsh plugin --profile <profile> add dsh-ptc-plus@0.5.5
```

---

<h3 id="en-v055">Host Compatibility</h3>

* Adapts to the public tool execution interface of DSH `0.2.2-alpha.3` while retaining the previous Host invocation contract; compatibility follows the public capabilities the Host provides

<h3>Fixes</h3>

* On the new DSH, a revision accepted by `edit_run_code` retains its original call relationship and the tools admitted for that run, and continues to follow Host policy and cancellation; later cells can continue using the revised state

<h3>Upgrade</h3>

* Node.js must satisfy both the plugin's `^22.19.0 || >=24.0.0` range and the selected DSH requirements; DSH `0.2.2-alpha.3` requires Node.js `>=24.9.0`
* No plugin configuration migration is needed; restart DSH after upgrading. A plugin upgrade does not rewrite historical session logs automatically

```sh
dsh plugin --profile <profile> add dsh-ptc-plus@0.5.5
```
