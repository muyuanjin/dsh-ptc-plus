<h3 id="cn-v056">宿主适配</h3>

* 声明 DSH 兼容范围 `>=0.2.1-0 <0.2.3`，由宿主按官方版本预检规则判断安装与启动资格；`0.2.2-rc.1` 在该范围内

<h3>修复</h3>

* 修复 0.5.5 将 DSH 兼容范围意外改成 `*` 的问题，恢复 0.5.4 的上下界；范围内的运行时接口仍按宿主公共能力选择

<h3>升级</h3>

* Node.js 需同时满足插件的 `^22.19.0 || >=24.0.0` 与所选 DSH 的要求；DSH `0.2.2-rc.1` 要求 Node.js `>=24.9.0`
* 无需迁移插件配置；升级后重启 DSH

```sh
dsh plugin --profile <profile> add dsh-ptc-plus@0.5.6
```

---

<h3 id="en-v056">Host Compatibility</h3>

* Declares the DSH compatibility range `>=0.2.1-0 <0.2.3`; the Host applies its official version preflight to installation and startup. This range includes `0.2.2-rc.1`

<h3>Fixes</h3>

* Fixes 0.5.5 unintentionally changing the DSH compatibility range to `*`, restoring the bounds from 0.5.4; runtime interfaces within that range continue to follow the Host's public capabilities

<h3>Upgrade</h3>

* Node.js must satisfy both the plugin's `^22.19.0 || >=24.0.0` range and the selected DSH requirements; DSH `0.2.2-rc.1` requires Node.js `>=24.9.0`
* No plugin configuration migration is needed; restart DSH after upgrading

```sh
dsh plugin --profile <profile> add dsh-ptc-plus@0.5.6
```
